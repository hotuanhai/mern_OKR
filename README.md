# 📊 Manage OKRs with Excel + NodeJS

This project provides a simple way to **manage Objectives and Key Results (OKRs)** stored in Excel.  
It includes NodeJS web to **validate OKR data** and **visualize progress** with graphs.

---

## 🚀 Features

- ✅ **Error checking**: validate Excel data for missing fields, invalid percentages, or inconsistent values  
- 📊 **Graphs & Charts**: automatically generate progress charts from OKR data  
- 🔄 **Excel integration**: read/write directly from `.xlsx` files  
- 📅 **Quarterly tracking**: monitor OKRs per quarter or per project cycle
